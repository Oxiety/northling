# Как пользоваться админкой northling

## Что уже подключено
- Decap CMS находится по адресу `https://northling.space/admin/`.
- В админке есть отдельные коллекции **Арты**, **Фотки** и **Oasis — альбомы и треклисты**.
- Загруженные изображения сохраняются в `img/uploads/`.
- Галереи читают данные из `data/arts.json` и `data/photos.json`, а дискография — из `data/oasis.json`.
- В разделе «Фотки» сейчас пустая галерея — добавляй снимки через CMS. Существующие три изображения оставлены в «Артах».

## Важно: один раз настроить GitHub-вход
Сайт выглядит как статический сайт на GitHub Pages (по CNAME), поэтому одной папки `admin` недостаточно: Decap должен получить разрешение записывать коммиты в репозиторий.

1. Открой `admin/config.yml`.
2. Замени `OWNER/REPOSITORY` на `владелец/репозиторий` GitHub, где лежит сайт. Проверь и имя ветки (`main`).
3. Подними OAuth-прокси для Decap CMS (например, отдельный небольшой сервис на Netlify/Vercel) и укажи его адрес в `base_url`. OAuth-прокси должен быть настроен на GitHub OAuth App с callback URL, который он сам показывает.
4. В настройках GitHub OAuth App укажи homepage сайта и callback URL OAuth-прокси. Не публикуй client secret в этом репозитории.
5. Закоммить и опубликуй изменения. После настройки входа открой `/admin/` и авторизуйся через GitHub.

До заполнения `OWNER/REPOSITORY` и `YOUR-OAUTH-PROXY` админка не сможет авторизоваться и сохранять изменения. Эти значения нельзя корректно угадать из ZIP-архива.

## Как добавлять контент после настройки входа
- **Арты** → «Галереи» → «Арты» → добавить элемент → загрузить картинку → сохранить и опубликовать.
- **Фотки** → «Галереи» → «Фотки» → добавить элемент → загрузить фотографию → сохранить и опубликовать.
- **Oasis** → «Музыка» → открыть альбом → отредактировать описание или список треков.

Если добавляешь картинки вручную, положи файл в `img/uploads/` и укажи путь `/img/uploads/имя-файла.jpg` в JSON.
