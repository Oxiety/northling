# Где менять содержимое сайта

## Самый простой способ — админка
После настройки GitHub-входа открой `https://northling.space/admin/`.
Там можно добавлять и удалять арты, фотографии, а также менять описания альбомов и треклисты Oasis. Картинки загружаются прямо с компьютера.

## Если редактируешь файлы вручную

### Арты
Открой `data/arts.json`. Каждый объект в `items` — одна карточка галереи:
```json
{
  "items": [
    {
      "title": "Название арта",
      "image": "/img/uploads/my-art.jpg",
      "alt": "Короткое описание изображения"
    }
  ]
}
```
Чтобы добавить арт, скопируй объект внутри массива `items`, поменяй название и пути. Чтобы удалить — удали весь объект вместе с запятой, если она нужна.

### Фотки
То же самое, но файл — `data/photos.json`. Сначала положи изображение в `img/uploads/`, затем добавь объект в `items`.

### Oasis
Открой `data/oasis.json`. В массиве `albums` лежат альбомы. У каждого есть:
- `title` — название;
- `year` — год выпуска;
- `description` — небольшой текст об альбоме;
- `tracks` — массив названий песен по порядку.

Можно менять текст, добавлять/удалять треки и добавлять альбомы, копируя существующий объект.

### Другие тексты и страницы
Тексты главной страницы и страницы персонажей пока находятся прямо в HTML:
- `index.html` — главная;
- `arts.html` — персонажи и раздел артов;
- `photos.html` — фотогалерея;
- `oasis.html` — вступление и структура музыкального раздела;
- `webdev.html` — проекты.

Для их ручного редактирования открой файл в редакторе кода, найди нужную фразу через поиск (`Ctrl+F`) и замени только текст между HTML-тегами. Старайся не удалять сами теги и атрибуты.
